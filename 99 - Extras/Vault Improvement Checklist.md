# Vault Improvement Checklist

Reviewed: 2026-11-08. This is a practical maintenance checklist, not a requirement to make every note connected.

## Linking policy

Resources do not need a link to an Area or Project. Add a link when it helps you use or find the material in a real context. A resource may remain independently searchable until you need it.

- From a Project, link to resources needed for its next tasks.
- From an Area, link to active projects and a small number of useful reference hubs.
- Between resources, link specific explanations, examples, or related concepts when the connection is useful.
- One direction is enough: Obsidian backlinks provide the reverse connection. Add an explicit return link only when navigation benefits.
- Do not duplicate notes or create an Area just to give every resource a parent.
